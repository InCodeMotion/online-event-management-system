## Git safety
- Do not rewrite published Git history; force-pushes or rebasing/amending/squashing published commits can discard collaborators' history.

## Project structure
- Keep the React preview as a demo client and deliver the required Java/Spring Boot/JDBC backend as a separate runnable source archive; this preserves the requested Java stack without pretending the hosted preview runs Java.
